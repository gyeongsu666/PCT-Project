==================================================
 PCT-Web (Piano/Chord Tab Converter) 실행 방법
==================================================

악보 이미지(PNG/JPG/PDF), MusicXML, MIDI 파일을 기타 타브악보로
변환·편집하는 웹 애플리케이션입니다. (ASP.NET Core + 웹 GUI)

--------------------------------------------------
1. 필수 설치: .NET 10 SDK  (이것 하나만 있으면 됩니다)
--------------------------------------------------
  다운로드: https://dotnet.microsoft.com/download
  - "SDK"를 설치해 주세요. (Runtime만으로는 안 됩니다)
  - 설치 확인: 터미널(PowerShell 또는 cmd)에서
        dotnet --version
    → 10.x.x 가 출력되면 정상입니다.

--------------------------------------------------
2. 실행
--------------------------------------------------
  1) 압축을 풀고, 터미널에서 API 프로젝트 폴더로 이동:
        cd <압축 푼 폴더>\PCT.Api
  2) 실행:
        dotnet run
     ※ 처음 실행 시 NuGet 패키지를 자동으로 내려받으므로
        인터넷 연결이 필요하며 1~2분 정도 걸릴 수 있습니다.
  3) 브라우저에서 접속:
        http://localhost:5000
  종료: 터미널에서 Ctrl+C

  (VS Code 사용 시: 폴더를 열고 F5 를 누르면 자동 빌드·실행됩니다.
   .vscode 폴더에 실행 설정이 포함되어 있습니다.)

--------------------------------------------------
3. 기능별 추가 요구사항
--------------------------------------------------
  ■ 추가 설치 없이 바로 되는 기능
    - MusicXML(.xml/.musicxml/.mxl), MIDI(.mid) → 타브악보 변환
    - 타브 편집(음 추가/삭제/이동, 박자 변경, 마디 추가/삭제/복사)
    - 키 조정(반음 단위), 타브 PNG 저장, 재생 커서, 변환 기록

  ■ 악보 "이미지/PDF" → 타브 변환 (광학 악보 인식, OMR) — 선택사항
    - 외부 프로그램 Audiveris 가 추가로 필요합니다.
    - 다운로드: https://github.com/Audiveris/audiveris/releases
      (Windows installer 버전 설치 권장)
    - 기본 경로(C:\Program Files\Audiveris\)에 설치하면 자동 인식됩니다.
      다른 경로에 설치한 경우, 환경변수 PCT_AUDIVERIS 에
      Audiveris.exe 의 전체 경로를 지정해 주세요.
    - Audiveris 가 없어도 프로그램은 정상 실행되며, 이미지 변환
      시도 시에만 안내 오류 메시지가 표시됩니다.

--------------------------------------------------
4. 사용 방법 (요약)
--------------------------------------------------
  1) 좌측 상단 [PNG 선택] 버튼 또는 드래그&드롭으로 악보 업로드
     (지원 형식: PNG, JPG, PDF, XML, MusicXML, MXL, MIDI)
  2) 변환된 타브악보 확인 → 좌측 슬라이더(운지 설정) 조절 후
     [다시 변환] 으로 결과 비교
  3) [수정] 버튼 → 편집 모드:
     - 프렛 클릭 = 숫자 수정 / 드래그 = 음 이동 / 빈칸 클릭 = 음 추가
     - 음표 우클릭 = 음 길이(박자) 변경
     - 마디선의 + = 마디 추가, 마디 위 × = 마디 삭제
     - 빈 곳 드래그로 마디 선택 → Ctrl+C / Ctrl+V = 마디 복사/붙여넣기
     - Ctrl+Z = 되돌리기, [저장] = 편집 결과 PNG 반영
  4) [타브 PNG 저장] 으로 이미지 다운로드, ▶ 재생 = 커서 따라가기
  5) 좌측 하단 "변환 기록"에서 이전 변환 결과를 다시 불러올 수 있음

--------------------------------------------------
5. 문제 해결
--------------------------------------------------
  - 'dotnet' 명령을 찾을 수 없음
      → .NET 10 SDK 설치 후 터미널을 새로 열어 주세요.
  - 5000 포트가 이미 사용 중이라는 오류
      → PCT.Api\appsettings.json 의 "Urls" 값을
        "http://localhost:5001" 등으로 바꾼 뒤 다시 실행하세요.
  - 이미지 변환 시 "Audiveris 실행 파일을 찾지 못했습니다"
      → 위 3번 항목의 Audiveris 설치/환경변수를 확인하세요.
  - 이미지 변환 시 "해상도가 너무 낮아 인식하지 못했습니다"
      → 300DPI 이상(한 페이지 기준 긴 변 2000px 이상)의
        선명한 악보 이미지를 사용해 주세요.

--------------------------------------------------
6. 프로젝트 구조
--------------------------------------------------
  PCT-Web.sln          솔루션 파일
  PCT.Core\            변환 핵심 라이브러리 (C#)
    MusicXmlParser.cs    MusicXML 파싱 (마디/박자/도돌이표)
    MidiParser.cs        MIDI 파싱 (양자화·화음 클러스터링)
    TabConverter.cs      운지 최적화 (동적계획법 비용 최소화)
    TabImageRenderer.cs  타브 PNG 렌더링 (SkiaSharp, 빔 기보)
  PCT.Api\             ASP.NET Core Web API + 웹 화면
    Program.cs           API 엔드포인트 (변환/렌더/기록)
    AudiverisRunner.cs   악보 이미지 인식(OMR) 외부 연동
    wwwroot\index.html   웹 GUI (단일 HTML 파일)

  ※ 개발/테스트 환경: Windows 11, .NET SDK 10.0.201
